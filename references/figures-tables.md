# 图表命名与编号强制规则

本文件是全文强制执行的图表规范。改动文稿时必须同步核对，不得遗漏。

## 一、编号格式

- 统一格式：`图X-Y`、`表X-Y`（数字之间用**半角横杠**；`图`/`表`与编号之间**不加空格**）
- X = 当前章节数，Y = 本章内序号
- **每章重新从 1 开始**，禁止跨章连续累加
- 图与表是**两套独立序列**，互不干扰
- 示例：第 1 章 `图1-1`、`图1-2` / `表1-1`；第 2 章 `图2-1` / `表2-1`

## 二、题注位置

| 对象 | 位置 |
| --- | --- |
| 图（流程图、架构图、截图、E-R 图等） | 题注在**图下方** |
| 表 | 题注在**表上方** |

## 三、题注格式

- 简明规范，**末尾不加任何标点**（不加句号）
- 完整释义图表内容，不模糊、不超长
- 编号与标题之间空一格，示例：`图3-1 系统总体架构设计图`、`表3-1 系统功能测试用例表`

## 四、正文引用

- 先正文引用、后出现图表
- 标准句式：`如图X-Y所示`、`如表X-Y所示`（编号与「所示」之间不加空格）
- 所有图表必须 100% 在正文有对应引用，**无遗漏、无闲置图表**

## 五、禁止行为

1. 禁止全文连续编号（图1、图2）
2. 禁止点号、横杠混用（图3.1 与 图3-1 不得混用）
3. 禁止图题在上、表题在下
4. 禁止题注末尾加标点
5. 禁止跨章连续累加序号

## 六、校验方法

改稿后用脚本或人工逐项核对，建议按下面的顺序做：

1. **提取题注**：按正文顺序找出所有以 `图X-Y` / `表X-Y` 开头的段落，作为题注清单。
2. **验证题注位置**：检查每个题注段落的前一个块是否为图片（图）或后一个块是否为表格（表）。注意连续多张图时，前一张图的题注的「后一个块」是下一张图，属于正常情况。
3. **检查标点**：确认所有题注末尾没有 `。．，；：` 等标点。
4. **检查编号**：按章分组统计序号，确认每章从 1 连续递增、无重复、无跨章累加、无点号格式。
5. **核对引用**：全文搜索 `如图X-Y所示` / `如表X-Y所示`，确认每个题注都有对应引用，且引用位置在图表之前；同时确认没有指向不存在图表的悬空引用。
6. **检查合并引用**：`如图3-12、图3-13所示` 这类合并引用属于合规写法；若要严格逐条对应，可改写为分别引用。

## 七、常见错误

| 错误 | 正确做法 |
| --- | --- |
| `图 3-1`（图与编号间有空格） | `图3-1` |
| `图3.1`（点号） | `图3-1` |
| `图1`、`图2` 全文连续编号 | 按章编号 `图1-1`、`图1-2` |
| 第 2 章接着第 1 章编号（图2-4 起） | 第 2 章从 `图2-1` 重新开始 |
| 题注末尾加句号 | 不加任何标点 |
| 「详见图3-1」「见表3-1」 | 「如图3-1所示」「如表3-1所示」 |
| 图题写在图上方 | 图题移到图下方 |

## 八、自动核对

`scripts/check_docx.py` 可直接核对本文件的可机检部分，改完稿跑一次即可：

```bash
python scripts/check_docx.py 论文.docx --only caption.format,caption.position,caption.sequence,caption.reference,caption.font
```

- `caption.format`：编号形式、编号与题名之间一个空格、末尾无标点
- `caption.position`：图题上方是否为图片、表题下方是否为表格
- `caption.sequence`：每章从 1 连续、无重复、无跳号、图与表各自独立
- `caption.reference`：每个题注是否都有前置正文引用、有无悬空引用
- `caption.font`：题注段落字号是否为 5 号（`sz=21`）

脚本判不了的（说明性文字是否完整释义图表、坐标轴是否标单位、引用图是否在题名右上角标了文献号），仍需人工过一遍。
