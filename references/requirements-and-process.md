# 论文要求、流程与提交规范

来源同上（校教发〔2024〕436 号）。本文件收录格式之外、但写作与交付时必须遵守的实质要求。格式类规则见 [format-spec.md](format-spec.md)。

> **本文件是 `school-436` 口径。** 中华职业学院计算机科学与技术（高职本科）2023 级／2027 届的流程与成果要求（14 周进度、开题答辩、中期检查、指导记录 ≥5 次、考勤 1/3 红线、周进展表、六大题目类型、按课题类型的成果清单、维普查重分级、成绩权重与五级制、7 项批阅要素、17 项归档清单）以 [zhonghua-cs-2023-spec.md](zhonghua-cs-2023-spec.md) 为准；写作方法与各章写法见 [cs-design-writing-guide.md](cs-design-writing-guide.md)。

## 一、论文组成要素及各自内容（第六条）

论文由以下部分构成，每部分都有明确的内容要求：

| 要素 | 应包含 |
| --- | --- |
| 开题报告 | 文献综述、选题意义、研究方法（研究思路及技术路线）、时间进度（阶段内容与时间安排）、指导教师意见 |
| 封面 | 论文题目、作者及学号、所属学院及专业、指导教师姓名、时间；采用学校统一封面格式 |
| 中、外文摘要 | 基本内容、主要观点、研究方法、创新点、理论与实践意义；300—500 字 |
| 关键词 | 能覆盖论文主要内容的通用词条，3—5 个，按外延层次从大到小排列 |
| 目录 | 按二级标题编写，层次清晰且与正文标题一致，须标注页码 |
| 正文 | 绪论（引言）、理论部分或实验设计部分（主体）、结论 |
| 注释 | 脚注；引刊物注作者、篇名、刊物名称、年卷期号；引著作注作者、著作名称、出版单位、出版年份、页码 |
| 附录 | 正文中不便列出的重要数据、数学推导、图表、符号说明、计算程序等，可选 |
| 参考文献 | 本人真正阅读过且有重要参考作用的文献；中英文不少于 20 篇，须有近两年文献 |
| 致谢 | 帮助研究工作的组织或个人、基金；提供条件的组织或个人；提出建议和帮助的人 |

## 二、选题要求（第七至十一条）

- 选题应符合**专业培养目标**，满足教学基本要求，鼓励学科交叉，拓宽知识面
- 尽可能结合理论研究、应用研究和实验室建设等实际问题，提高发现问题、分析问题、解决问题的能力
- **学术型专业**：选题应来自教师专业实践、科研课题
- **应用型专业**：选题应以实验、实习、工程实践和社会调查等实践性工作为基础
- 选题注意**三个结合**：结合毕业实习、结合实际问题、结合专业知识
- 选题宜是社会实践报告、专题课作业、科研活动和课外学术活动的延续与提升

## 三、开题报告（第十二至十四条）

- 选题确定后，**先提交开题报告，经指导教师同意后方可进入撰写阶段**
- 开题报告内容：1) 选题的意义；2) 文献综述；3) 研究方法（或技术路线）；4) 时间进度
- 开题报告及教师指导意见需存档

## 四、正文与字数（第六条（五）、第十五条）

- 正文结构：绪论（引言）→ 理论部分或实验设计部分（主体）→ 结论
- 字数：**10000 字以上**；外语类专业 **8000 单词以上**
- 理工科类做毕业论文设计的，须提交论文或实验成果，并考查实验过程和设计成果（软件、程序、开发产品等）
- 论文题目严格控制在 **25 字以内**，内容较丰富时可用副标题补充

## 五、查重与提交（第十六条、第二十四条）

- 学院本科毕业论文定稿后**必须通过相似性检测**
- 提交检测的论文文件命名规则：**学院 + 专业班级 + 学号 + 论文作者姓名 + 指导教师姓名 + 题目**
- 相似比 **≥20% 不能参加答辩**，须修改后二次检测；二次检测仍不合格者，待合格后参加下一届答辩
- 最终稿须保证相似比低于 20%，学院对最终稿再做检测
- 定稿后**一式两份**、按规定格式向指导教师提交打印稿；经指导教师、教学秘书、评阅人、答辩小组流转后，由学生按规定顺序装订交教学秘书存档
- 以篡改伪造电子文档、弄虚作假等方式应付检测的，经学院核实认定后取消本学期答辩资格

## 六、装订与装袋（第二十五、二十六条）

**装订顺序**：封面 → 原创性及知识产权声明 → 中文摘要及关键词 → 英（外）文摘要及关键词 → 目录 → 正文 → 附录 → 参考文献 → 致谢 → 封底；均单独起页，**左侧装订**并切割整齐。

**装袋顺序**：

1. 毕业论文（设计）原件（含装订顺序中的全部内容）
2. 开题报告表
3. 云南财经大学学生毕业论文（设计）工作表格
4. 云南财经大学本科生学位论文相似性检测报告
5. 云南财经大学学生毕业实习手册

## 七、评审、答辩与成绩（第十七至二十三条，背景信息）

- 除指导教师外，学院另指定 1 名评阅人，对选题、学术水平及创新点、论证能力、写作水平、外文翻译质量作认定并评分
- 答辩小组由 3 名教师组成，其中 1 人为组长；指导教师须于答辩前 10 天提交论文与评阅意见
- 学生答辩先介绍基本思想与主要内容（15 分钟），再回答质疑问题；质疑问题提前 30 分钟告知准备
- 总评成绩：写作成绩 =（指导教师成绩 + 评阅人成绩）/ 2；总评 = 写作成绩 × 80% + 答辩成绩 × 20%（艺术类为 60% + 40%）
- 评价分五级：优秀、良好、中、及格、不及格
- 质量抽查：答辩结束后学院组织专家抽查，原则上按毕业生人数的 20%—25%
- 优秀论文原则上成绩 90 分以上，按毕业生总数 1—2% 评定

## 八、学术诚信红线（第三十、三十一条）

- 学校严厉打击学位论文**买卖、代写**行为
- 对参与购买、代写学位论文的学生，给予**开除学籍**处分；已获学历证书、学位证书的，依法予以撤销
- 论文须由学生独立完成，指导教师负责审查原创性

> 涉及学术诚信的表述用于提醒风险，不构成法律意见。正式处理以学校认定为准。

## 九、附表与评分要素（原文附表 1、2）

436 号文正文之后附两张表，写作与交付时会直接用到：

- **附表 1 开题报告表**：论文（设计）名称、来源、类型（A—理论研究；B—应用研究；C—软件设计等）、导师、学生姓名、学号、专业；正文栏为文献综述、选题意义、研究方法、时间进度；另有指导教师意见、教学系意见、学院意见三栏签名
- **附表 2 毕业论文工作管理表格**，包含以下表：

| 表格 | 用途 / 关键数字 |
| --- | --- |
| 本科生毕业论文（设计）工作表格 | 题目、学院、专业班级、学号、论文作者、指导教师、职称 |
| 本科生毕业论文（设计）成绩表 | 写作成绩（指导教师评定 + 评阅人评定 的平均）、答辩成绩、总评成绩；注：总评 = 写作成绩 × 80% + 答辩成绩 × 20%，三成绩中有不及格者取最低分 |
| 指导情况记录表（1）（2） | 指导教师逐次记录选题指导、写作过程指导与定稿意见，注明时间并签名 |
| 指导教师评分评议要素表 | 见下方分值 |
| 评阅表 | 评阅人对选题、学术水平及创新点、论证能力、写作水平、外文翻译质量作认定并评分 |
| 答辩记录及评审表（答辩小组用） | 论文（设计）内容 40、准备过程 10、创新 10、答辩 40，合计 100 |
| 专家抽查评估表（经、管、文、法专业适用 / 理工科专业适用） | 按 A、B、C、D 四级评定，指标覆盖选题质量、能力水平、成果质量、评阅与答辩 |
| 优秀毕业论文（设计）推荐表 | 推荐意见需说明对内容、质量、学术水平（含文字、图表、公式）的评价与推荐理由，并确认符合写作规范 |

评分要素与分值（指导教师评分评议要素表，两类专业同权重）：

| 一级指标 | 分值 | 二级指标 |
| --- | --- | --- |
| 选题意义 | 20 | 选题符合专业培养目标、体现专业特点、把握学术前沿 |
| 写作安排 | 15 | 过程管理（工作量饱满、进度合理）、写作形式符合要求 |
| 逻辑构建 | 20 | 逻辑结构（体系完整、层次分明）、论文表达（文笔流畅、用语规范） |
| 专业能力 | 25 | 调研分析及解决问题能力、创新性 |
| 学术规范 | 20 | 学术诚信（无抄袭剽窃伪造篡改买卖代写）、格式规范 |

> 第二十三条要求：上列评阅情况的各种表格随每个学生的毕业论文**装订成册并存档**——它们不进论文正文，但都在装袋与归档范围里。
