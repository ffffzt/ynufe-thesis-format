# 云南财经大学本科毕业论文格式 Skill

一个给 AI 编码助手用的技能包，把《云南财经大学本科生毕业论文（设计）管理规定（修订）》（校教发〔2024〕436 号）里的排版要求整理成可执行的规则，让 AI 在撰写、排版、检查论文时直接照做，而不是套用通用论文模板。

## 它能做什么

- 按学校规定设置页面、字体、字号、行距、页码与页眉
- 组织封面、原创性声明、中英文摘要、目录、正文、参考文献、致谢的**顺序与页码分段**
- 写摘要与关键词（中文 300—500 字、3—5 个关键词；外文用 Times New Roman 小 4）
- 生成符合要求的两级目录，并保证目录条目可点击跳转
- 检查参考文献数量、著录格式与近两年文献要求
- 强制执行图表命名规则（`图X-Y` / `表X-Y`、图题在下、表题在上、正文先引用）
- 交付前做格式自检，并要求把文档渲染成图片逐页核对版面

## 安装

把整个文件夹放进你的技能目录即可。常见位置：

| 环境 | 目录 |
| --- | --- |
| Codex | `~/.codex/skills/ynufe-thesis-format/` |
| 通用 agents 技能目录 | `~/.agents/skills/ynufe-thesis-format/` |
| Claude Code | `~/.claude/skills/ynufe-thesis-format/` |

```bash
git clone <this-repo> ~/.codex/skills/ynufe-thesis-format
```

安装后重新开一个会话，技能才会被加载。

## 目录结构

```
ynufe-thesis-format/
├── SKILL.md                          主入口：触发条件与核心规则速查
├── references/
│   ├── format-spec.md                完整格式细则（页面、字体、页码、目录、参考文献等）
│   ├── figures-tables.md             图表命名与编号强制规则及校验方法
│   └── word-implementation.md        Word / python-docx 落地要点与常见坑
├── agents/openai.yaml                UI 元数据
└── LICENSE
```

技能采用渐进式加载：`SKILL.md` 只放最常用、最容易出错的规则，细节放在 `references/` 里按需读取。

## 几条容易被忽略的规则

- 正文标题按黑体处理：一级、二级 4 号，三级、四级小 4。校发文件里「小 4 号黑体」那句其实是**目录条目**的规定，不是正文标题，很容易读串。
- 标题四级编号是 `一、` → `（一）` → `1` → `（1）`，分别对应章、节、目、子目；括号用全角，一级和二级标题上下各空一行，目录只列到二级。
- 页面：A4，上下 2.54cm、左右 3.17cm，页眉 1.5cm、页脚 1.75cm，全文 1.5 倍行距。
- 页码分两段：声明、摘要、目录用大写罗马数字；正文起用阿拉伯数字并从 1 重新开始。
- 图表编号必须按章重置，且图题在下、表题在上，题注末尾不加标点。
